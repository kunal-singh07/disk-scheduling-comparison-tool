# disk-scheduling-comparison-tool
Implementation and comparison of FCFS, SSTF, SCAN, C-SCAN and LOOK disk scheduling algorithms.


how to run and check the file :
First clone this git repo in your folder using (in VS code terminal):- git clone https://github.com/kunal-singh07/disk-scheduling-comparison-tool.git
then run main.py


sample input:
Enter total number of disk tracks: 200
Enter initial head position: 53
Enter number of disk requests: 8
Enter disk requests separated by spaces:
98 183 37 122 14 124 65 67
Enter initial direction (left/right): right
Enter seek time per track (in ms): 0.1


before running insure you have python in system and also through terminal do (pip install matplotlib) :- required for running visualisation.py
